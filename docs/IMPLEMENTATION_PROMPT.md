# Промпт внедрения Luma Studios

Создать русскоязычный интерактивный прототип библиотеки в пустом репозитории. Стек: React 19, Vite, Lucide, localStorage. Только frontend; backend не требуется для демонстрации. Никаких внешних записей или отправки персональных данных.

## Входные данные и ограничения

Текстовый промпт прочитан полностью. ZIP «рефернсы luma-studio (6).zip» недоступен: download_file отклоняет файлы больше 32 MiB. Перечисленные в промпте другие архивы, видео, логотип и PNG отдельно не предоставлены. Не утверждать, что они изучены. Не рисовать похожий знак взамен оригинального логотипа: использовать временную типографическую надпись Studios / Luma. Оставить возможность подставить assets/logo.svg и исходные фоны. Референсную точность считать непроверенной.

## Дизайн

База #000000, светлая тема #FFFFFF, поверхность #151515, линия #303030, вторичный текст #A3A3A3, основной текст #F7F7F7. Цвет только у обложек, фона, логотипов сервисов и жанров. Системная гротескная типографика, книжная антиква только в читалке. Крупный полноразмерный центральный постер и соседние обложки — главный визуальный акцент. Отказаться от крупного маркетингового текста и сетки одинаковых декоративных карточек. Навигация слева на ПК, снизу на телефоне. Подписи строго вне обложек. Кнопки pill, единый focus-visible, поля с резервом под ошибку. SVG интерфейса Lucide (ISC).

## Экраны и состояния

1. Вход: выбор метода, email/телефон/Luma ID, ошибки; OAuth не настроен. Четыре ячейки кода, вставка, backspace, неверный код, повтор, успех. Демо-код 1234, никакого сообщения о реальной отправке.
2. Онбординг: язык, четыре формата с мультивыбором, темы, избранные с поиском, рекомендации, пропуск, приветствие и переход.
3. Главная: циклическая карусель с постоянными img, клавиатура/свайп/стрелки, Продолжить.
4. Каталог: поиск по автору/названию, формат, жанр, сортировка, пусто, сброс. Реальный язык издания.
5. Произведение: обложка, описание, главы, автор, герои, отзывы, заметки, библиотека/полка. Не выдумывать рейтинги.
6. Читалка: настоящие публично доступные главы, страницы, шрифт, тема, оглавление. Иллюстрированный демонстрационный разворот с ручной разметкой областей, масштаб/панорамирование и возврат.
7. Аудио: настоящий локальный синтезированный файл, метаданные размера, play/pause, seek, speed, timer, chapters. Заметки/отзывы сохраняются.
8. Библиотека: библиотека/полки/архив, создание полки, загрузка иконки, составной постер, добавление/удаление, архив/восстановление, согласованные счётчики.
9. Профиль: аватар, редактирование inline, настройки языка/темы, аналитика по фактическим событиям, период/CSV.
10. Интеграции: Telegram/Notion demo, входящие/выбор/проверка/результат, изменяемый mapping Notion. Экспорт сервисов demo, настоящий локальный CSV с BOM и корректным экранированием.

## Проверка и запись

Пройти полный путь и ошибки Playwright в Chromium. Размеры: 1920×1080, 1440×900, 390×844, 390×600; увеличенный текст, reduced-motion. Записать реальное взаимодействие в 1920×1080 и мобильном CSS viewport 432×768 с deviceScaleFactor 2.5; итоговое видео 1080×1920. MP4 H.264 yuv420p 30fps faststart, проверить ffprobe, декодирование и выборочные кадры. Сохранять результаты теста машинно. Архив исходников без node_modules, кэша и git. Документировать фактические ограничения.
