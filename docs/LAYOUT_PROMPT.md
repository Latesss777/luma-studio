# Промт: каталог Luma в структуре манга-платформы

Задача — перестроить интерфейс Luma Studios в структуре крупного каталога манги
(эталоном по раскладке служит ReManga), сохранив бренд Luma и не перенося чужой
контент.

## Что переносим (структура и поведение)

- Фиксированная шапка 60 px: логотип, «Каталог», «Топы», меню «…», поиск с
  выпадающими результатами, «Закладки», уведомления, аватар профиля.
- Главная открывается сразу, без входа и онбординга.
- Главная, сверху вниз:
  1. Лента популярного на всю ширину окна, без заголовка.
  2. «Продолжить чтение» — только если есть прогресс.
  3. «Горячие новинки» — лента с кнопками прокрутки и ссылкой на каталог.
  4. Три колонки рядом: «Новый сезон», «В тренде», «Популярно сегодня»
     (по 5 строк: маленькая обложка, название, тип и год, оценка).
  5. «Популярное» — лента.
  6. «Коллекции» — широкие карточки подборок.
  7. «Топ тайтлов» — лента с переключателем по типу.
  8. «Свежие главы» — лента.
  9. «Последние обновления» — список строк «тайтл — глава — когда».
- Карточка: обложка 2:3 со скруглением, оценка-плашка в правом нижнем углу
  обложки, под обложкой «Тип Год» мелко и название в две строки.
- Каталог: заголовок, сортировка, чипы типов, кнопка «Фильтры» (жанры,
  статус, год, минимальная оценка), сетка 6 колонок на ПК, 3 на телефоне.
- Топы: рейтинг списком с местом, переключатели типа и периода.
- Страница тайтла: обложка слева, справа название, тип, год, статус,
  оценка, «Читать»/«Продолжить», «В закладки» с категориями, вкладки
  «Главная», «Главы (N)», «Обсуждения». На «Главной» — описание, жанры,
  статистика, похожие тайтлы.
- Читалка: для комиксов — вертикальная лента страниц, верхняя панель с
  выбором главы и переходом на следующую; для книг — существующая текстовая.
- Закладки: вкладки «Читаю», «Буду читать», «Прочитано», «Любимое»,
  «Брошено» с количеством, сетка карточек.
- Профиль и полки — существующие экраны внутри новой шапки.
- Нижняя навигация на телефоне.

## Чего не переносим

Название, логотип, цвета бренда, обложки, описания, тексты и каталог
ReManga. Всё содержимое — свои 6 книг (общественное достояние) и
демо-тайтлы Luma с обложками, которые рисуются кодом; демо помечены.
Реальный каталог подключается позже через легальные источники метаданных
или загрузки авторов.

## Оформление Luma

- Тёмная тема по умолчанию, тёплый «лунный» золотой акцент вместо синего,
  холодные чернильные нейтрали; светлая тема из тех же токенов.
- Шрифт Manrope (локальный), контраст весов вместо второго семейства.
- Логотип Luma в шапке.
- Анимации — только в ответ на действия пользователя.

## Критерии готовности

- `npm run build` без ошибок, приложение стартует на главной.
- Все экраны работают на 1440 px и 400 px без горизонтальной прокрутки
  страницы.
- Закладки, оценки, прогресс чтения и отметки прочитанных глав
  сохраняются в localStorage.
