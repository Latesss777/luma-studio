# Luma Studios

Интерактивный прототип личной библиотеки: вход, онбординг, карусель, каталог, чтение, иллюстрации, аудио, полки, профиль, аналитика и демонстрационные интеграции.

Черновые записи текущей версии и архив исходников находятся в [deliverables](https://github.com/Latesss777/luma-studio/tree/main/deliverables). Технические параметры MP4 проверены; точные логотип и космические фоны ожидают отдельных исходных файлов до 32 MiB. Проверки и ограничения: [отчёт](docs/VERIFICATION.md).

## Запуск

Нужен Node.js 22+.

```bash
npm ci
npm run dev
```

Открыть адрес, который напечатает Vite (обычно http://localhost:5173). Вход по почте, телефону или Luma ID работает в **деморежиме**, код `1234`. Настоящие SMS, письма и OAuth-запросы не отправляются. Яндекс ID требует отдельной настройки OAuth; пароль Яндекса не запрашивается.

```bash
npm run build
npm run preview -- --port 5173
```

Тексты, шрифт и аудио включены в репозиторий. При `npm ci` изображения автоматически загружаются из публичных репозиториев Standard Ebooks и проверяются по SHA-256 (`scripts/asset-manifest.json`). В ZIP-архиве исходников эти изображения уже включены. Повторная проверка: `npm run assets`. После установки все материалы доступны локально, без сторонних API во время работы приложения. Если первоисточник изменился, загрузка останавливается вместо тихой подмены файла. Издания — на английском; русские названия являются названиями каталога, а не обещанием перевода. Выбор русского языка показывает сообщение об отсутствии русского издания. Каталог содержит 6 книг; для Алисы доступно 12 глав, для других изданий — 2–3 начальные главы. Для манги и вебтунов предусмотрены честные пустые состояния. Покадровый режим демонстрируется на листе из оригинальных иллюстраций Тенниела с **ручной** разметкой, не на обложке и не как автоматическое распознавание.

## Проверки

```bash
npx playwright install chromium
npm run dev -- --port 5173  # в первом терминале
npm test                   # во втором
```

По умолчанию используется системный `/usr/bin/chromium`, если установлен; иначе Chromium из Playwright. Другой браузер можно указать через `CHROMIUM_PATH`. Адрес приложения: переменная `LUMA_URL`, каталог отчёта: `LUMA_TEST_DIR` (по умолчанию `work/verification`). Сценарий проверяет реальную работу интерфейса и сохранение данных, ошибки входа, адаптивность, импорт/экспорт и содержимое скачанного CSV. Скриншоты и `results.json` сохраняются в каталоге отчёта.

## Воспроизведение записи

Нужны Chromium и **FFmpeg с libx264** в PATH. Запустить приложение на 5173, затем:

```bash
npm run record -- desktop
npm run record -- mobile
node scripts/inspect-videos.mjs
```

Результат в `output/`; другой каталог задаётся `LUMA_OUTPUT`. Запись непрерывно снимает работающий браузер, ввод и переходы. Мобильный viewport — 432×768 CSS-пикселей, масштаб захвата 2.5, физический кадр 1080×1920. ПК — 1920×1080. Телефонная версия открывается в iframe с настоящим viewport 432×768, масштабированном до кадра 1080×1920. Захват идёт из композитора Chromium при перерисовках; временные отметки сохраняют длительность состояний. FFmpeg создаёт 30 fps, H.264, ограниченный цветовой диапазон yuv420p и faststart. Видео без звуковой дорожки: воспроизведение аудио проверяется через настоящий HTMLAudioElement, системный звук не захватывается. Это запись интерфейса, а не монтаж статичных экранов. Промежуточные кадры и таймлайн остаются в `work/record-*`.

## Архитектура

- `frontend/src/` — модули `auth`, `onboarding`, `home`, `catalog`, `title`, `reader`, `audio`, `library`, `profile`, `integrations`, общие UI и состояние.
- `frontend/public/assets/` — локальные первоисточники обложек и иллюстраций, шрифт и аудиофайл.
- `backend/` — граница для будущего сервера; backend в текущем прототипе отсутствует.
- `scripts/verify.mjs` — браузерная проверка, `scripts/record.mjs` — запись.
- `docs/IMPLEMENTATION_PROMPT.md` — план и критерии внедрения.
- `docs/SOURCES.md` — источники, лицензии и ограничения исходных материалов.
- `docs/VERIFICATION.md` — фактически выполненные проверки и технические характеристики видео.

Состояние хранится в `localStorage` под ключом `luma-studios-v1`. Импорт Telegram/Notion и передача экспорта — демонстрационные; добавление примеров изменяет только локальную библиотеку. CSV — настоящий UTF-8-файл с BOM, разделителем `;`, экранированием кавычек и многострочных заметок. Аналитика строится по фактическим локальным событиям, не утверждает, что открытая страница прочитана. Оценки появляются только из сохранённых пользователем отзывов.

## Ограничения материалов

Приложенный ZIP «рефернсы luma-studio (6).zip» превышает лимит инструмента загрузки в 32 MiB и не был прочитан. Исходный логотип, фоны, видео и перечисленные в тексте дополнительные архивы отдельно недоступны. Поэтому используется **временная типографическая надпись** Studios / Luma, а фон взят из открытого издания. Совпадение с недоступными референсами не заявляется. После получения исходников нужно заменить `Brand` и фоновые изображения, а также сверить композиции. Это рабочий прототип, не production-приложение с реальными аккаунтами и синхронизацией.
