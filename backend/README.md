# Backend

В прототипе нет сервера приложения. Все изменения сохраняются локально в браузере. Настоящая авторизация, отправка кодов, интеграции и синхронизация требуют отдельной реализации backend и настроек провайдеров. Этот каталог фиксирует границу архитектуры; серверная логика не помещена во frontend.
