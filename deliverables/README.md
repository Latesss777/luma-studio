# Материалы текущей версии

- `Luma_Studios_Desktop.mp4` — 1920×1080, 3:09.53.
- `Luma_Studios_Mobile.mp4` — 1080×1920, 3:18.20.
- `Luma_Studios_Source.zip` — исходники и локальные изображения; запуск описан в README внутри архива.
- `Luma_Studios_Example.csv` — настоящий пример экспорта из записанного пользовательского пути, UTF-8 с BOM.
- `video-checks.json` — фактические результаты проверки MP4 и таймлайн сцен.

Оба видео: H.264, yuv420p, 30 fps, faststart. Они показывают полный путь по работающему интерфейсу. Записи **черновые по оформлению**: оригинальные логотип и космические фоны ожидают доступных отдельных файлов. Вход и интеграции демонстрационные, данные локальные, аудио в плеере — настоящий синтезированный фрагмент. Ролики без звуковой дорожки.
