# Материалы текущей версии

- `Luma_Studios_Desktop.mp4` — 1920×1080, 3:07.60.
- `Luma_Studios_Mobile.mp4` — 1080×1920, 3:15.47.
- `Luma_Studios_Source.zip` — исходники и локальные изображения; запуск описан в README внутри архива.
- `Luma_Studios_Example.csv` — настоящий пример экспорта, UTF-8 с BOM.
- `video-checks.json` — фактические результаты проверки MP4 и таймлайн сцен.

Оба видео: H.264, yuv420p, 30 fps, faststart. В роликах используются предоставленные космические фоны и оригинальный логотип. После приветствия показан переход через его знак к главной. Вход и интеграции демонстрационные, данные локальные. Аудио в плеере — настоящий синтезированный фрагмент, но сами ролики без звуковой дорожки.
