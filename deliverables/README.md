# Материалы текущей версии

- `Luma_Studios_Desktop.mp4` — 1920×1080, 3:07.53.
- `Luma_Studios_Mobile.mp4` — 1080×1920, 3:15.60.
- `Luma_Studios_Source.zip` — исходники и локальные изображения; запуск описан в README внутри архива.
- `Luma_Studios_Example.csv` — настоящий пример экспорта, UTF-8 с BOM.
- `video-checks.json` — фактические результаты проверки MP4 и таймлайн сцен.

Оба видео: H.264, yuv420p, 30 fps, faststart. В роликах уже используются предоставленные космические фоны. Для замены временной надписи ещё нужен отдельный файл логотипа; поэтому полная визуальная финализация пока не заявляется. Вход и интеграции демонстрационные, данные локальные. Аудио в плеере — настоящий синтезированный фрагмент, но сами ролики без звуковой дорожки.
